# MI PASS Architecture

Frontend: Next.js / React / TypeScript
Backend: FastAPI
Database: PostgreSQL
Cache/jobs: Redis

Main modules:
- Authentication
- Resident dashboard
- My Society
- My Services
- Provider authorization
- Service requests
- Provider portal
- Reviews
- Complaints
- My Life directory
- Admin analytics
- Notifications

Future:
payments, digital MI PASS ID, visitor passes, facility booking, AI assistant.
